Дуб Ремонт — ВИПРАВЛЕНИЙ КОМПЛЕКТ ДЛЯ GITHUB PAGES
=================================================

Тепер сайт не використовує зовнішніх фото Pexels.
Усі 31 фотографії є у папці images/: 7 попередніх і 24 додаткові локальні WebP.

ОНОВЛЕННЯ:
1. Відкрийте GitHub → потрібний репозиторій.
2. В корінь репозиторію покладіть index.html.
3. ЗАВАНТАЖТЕ УСЮ ПАПКУ images із цього архіву, включно з 24 новими файлами.
   Усі файли мають опинитися у /images/, НЕ в /images/images/.
4. У Settings → Pages оберіть Deploy from branch → main → /(root).
5. Зробіть оновлення сторінки без кешу або відкрийте інкогніто.

УВАГА:
- Нові 9 фото для послуг є тематичними згенерованими ілюстраціями; кожна відповідає назві.
- 10 фото галереї — демонстраційні інтер'єри з наданих раніше матеріалів.
  Деякі не відповідають назвам конкретних приміщень, наприклад, ванна,
  дитяча або сходи; це лише робочі візуальні замінники до надання точних фото.
- Портрети колективу — ілюстративні, не фотографії реальних працівників.
- Не використовуйте демо-фото як докази виконаних компанією ремонтів.
- Демонстраційні адреси, телефон, імена, цифри, відгуки необхідно замінити на реальні.

Якщо в GitHub Pages картинки знову відсутні:
- Відкрийте https://<USER>.github.io/<REPO>/images/service-01-measure.webp
- Якщо 404 — файл не завантажений, інша гілка або неправильна назва/регістр.
- Перевірте, що всі зображення лежать поряд із index.html у папці images.
