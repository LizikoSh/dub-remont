ДУБ РЕМОНТ — ВИПРАВЛЕНА ВЕРСІЯ ДЛЯ GITHUB PAGES

Основні зміни:
• Головна сторінка має обов'язкову назву index.html.
• Сім WebP-фотографій лежать у папці images, а їхні посилання починаються з ./images/.
• HTML більше не містить важких вбудованих base64-фото (це була версія для вставки в Google Sites).
• Скориговано відступ під час прокрутки до калькулятора під закріпленою шапкою сайту.
• Логіку калькулятора, тексти сторінок і решту оформлення збережено.

ЗАВАНТАЖЕННЯ НА GITHUB
1. Розпакуйте ZIP-архів на комп'ютері.
2. У корені репозиторію мають лежати файли index.html, index.txt та папка images із 7 файлами .webp.
   ВАЖЛИВО: НЕ завантажуйте ZIP у GitHub як є; потрібно завантажити його розпакований вміст.
3. Відкрийте репозиторій > Settings > Pages > Build and deployment.
   Виберіть Deploy from a branch, гілку main та папку /(root), потім Save.
4. Відкрийте адресу, яку покаже GitHub Pages. Головною сторінкою буде index.html.

КОД У TXT
index.txt — повний HTML-код у форматі текстового файлу для перегляду та копіювання.
На сайті має бути index.html, а не index.txt.
